# Student Performance Dataset Analysis

## Objective
Analyze student performance data and identify factors affecting academic outcomes.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Data Cleaning
- Checked missing values
- Checked duplicate rows
- Verified data types

## Key Insights
1. Students with more study hours tend to score higher.
2. Attendance positively affects final grades.
3. Gender distribution is balanced.
4. Final grades are concentrated in a specific range.
5. Strong correlation exists between study hours and grades.

## Conclusion
Student performance is influenced by study hours and attendance. Regular study habits improve academic outcomes.
